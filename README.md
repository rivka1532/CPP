# C++ Programming Course

A collection of C++ programming exercises and assignments organized by lessons. This repository contains coursework for learning C++ programming fundamentals and advanced concepts.

## 📚 Course Structure

### Lesson 2
- Fundamental C++ concepts
- Basic syntax and data types
- Control structures and loops
- Functions and basic algorithms

### Lesson 3
- Advanced C++ programming
- Object-oriented programming concepts
- Classes and objects
- Memory management and pointers

## 🚀 Getting Started

### Prerequisites
- C++ compiler (GCC, Clang, or MSVC)
- IDE or text editor (Visual Studio, Code::Blocks, CLion, or VS Code)
- Basic understanding of programming concepts

### Compilation and Execution

1. Clone the repository:
   ```bash
   git clone https://github.com/rivka1532/CPP.git
   cd CPP
   ```

2. Navigate to a lesson folder:
   ```bash
   cd lesson2
   ```

3. Compile the C++ files:
   ```bash
   g++ -o program filename.cpp
   ```

4. Run the compiled program:
   ```bash
   ./program        # On Linux/Mac
   program.exe      # On Windows
   ```

## 🎯 Learning Objectives

Through these lessons, you'll learn:

### Lesson 2 Focus:
- **Basic Syntax**: Variables, constants, and data types
- **Input/Output**: Using cin and cout
- **Control Flow**: If statements, switch cases, loops
- **Functions**: Declaration, definition, and calling
- **Arrays**: Basic array operations

### Lesson 3 Focus:
- **Object-Oriented Programming**: Classes and objects
- **Constructors and Destructors**: Memory management

- **Polymorphism**: Virtual functions and overriding
- **Pointers and References**: Dynamic memory allocation

## 📖 Key C++ Concepts Covered

- **Data Types**: int, float, double, char, bool, string
- **Operators**: Arithmetic, logical, comparison, assignment

- **Classes**: Encapsulation, inheritance, polymorphism
